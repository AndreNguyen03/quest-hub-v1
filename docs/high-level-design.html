Key Flows
Hoàn thành Task
Learner tick Task → Quest Module tạo TaskCompletion → recalc progress + evaluate completion_rule → publish task.completed → World cập nhật District + mở khóa Building + Social thêm Activity vào Feed + Notification gửi → nếu rule thỏa: publish quest.completed → World kiểm tra & unlock Achievement
Fork Quest
Learner click "Use Quest" → Quest Module tạo PersonalQuest + copy chapters/tasks + snapshot completion_rule → publish quest.forked → Social thêm Activity + Marketplace invalidate cache
Tìm kiếm Quest
User nhập keyword → Marketplace Module → Redis cache trending? → Elasticsearch query → trả kết quả đã rank
Publish Quest
Creator click Publish → Marketplace Module đổi visibility → PUBLIC → publish quest.published → Elasticsearch index quest + Social thêm Activity
AI chấm bài submission
Learner nộp bài SUBMISSION/PRACTICE → AI Module lấy rubric từ task.config → Claude chấm theo rubric → JSON {status, score, feedback} → pydantic validate + INSERT submission_grades → PASS → publish submission.graded → Quest Module tạo TaskCompletion + evaluate completion_rule + Notification gửi kết quả
AI Coach chat (tool calling)
Learner gửi tin nhắn → Claude quyết định gọi tool (get_progress / get_streak / get_achievements / get_upcoming_tasks) → AI Module dispatch tool → query internal Quest/World API (READ only) → trả kết quả tool về Claude → streaming reply qua SSE → INSERT coach_messages (USER + ASSISTANT + TOOL)
Architectural Decisions
Event-driven World update
World Module không nhận sync call từ Quest Module. District tự cập nhật khi nhận task.completed — đúng với thiết kế "World chỉ là visualization của thực tế."
CompletionRule cấu hình được
Quest hoàn thành theo tiêu chí thật (quiz ≥ 80% + submission), không cứng nhắc theo checklist. Rule được snapshot khi fork để Learner chạy độc lập.
Elasticsearch riêng cho search
PostgreSQL full-text search không đủ cho relevance ranking phức tạp. Elasticsearch xử lý keyword, filter kết hợp, và ranking.
Redis cache cho Marketplace
Trending và Popular đọc nhiều, tính toán nặng. Cache invalidate khi nhận quest.rated hoặc quest.forked.
Single PostgreSQL
Learning project — không tách DB theo service. Social, Notification, AI dùng chung DB. Dễ query cross-domain, migrate sau khi cần scale thật.
No XP entity
XP là calculated metric từ TaskCompletion. Không lưu riêng, tính on-the-fly khi World cần render District level.
Quest = Template · PersonalQuest = Instance
Fork pattern đảm bảo Quest gốc bất biến. PersonalQuest copy chapters/tasks — Creator update không ảnh hưởng Learner đang chạy.
AI Grader không tự PASS
Kết quả chấm chỉ qua event submission.graded, Quest Module quyết định tạo TaskCompletion. LLM lỗi/timeout → 503, không bao giờ tự coi là PASS.
AI Coach chỉ đọc (read-only agent)
Coach dùng tool calling nhưng mọi tool chỉ READ qua internal API. Không có tool nào write quest — tránh AI tự ý thay đổi tiến trình của user.
